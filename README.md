# TravelLog

A simple Java console application for tracking trips and destinations.

## Features
- Add a trip
- View all trips
- Search trips by destination
- Delete a trip
- Exit the application

## Java Concepts
- Classes and objects
- ArrayList
- Scanner
- Loops
- Methods
- Encapsulation
- Basic CRUD operations

## Run

```bash
javac src/TravelLog.java -d out
java -cp out TravelLog
```

No database or external libraries are required.
